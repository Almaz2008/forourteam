# Обнаружение тропических циклонов на спутниковых снимках
Данный проект представляет собой экспериментальный скрипт на Python для автоматического обнаружения тропических циклонов на спутниковых изображениях с использованием методов компьютерного зрения (OpenCV) и проверки метеорологических параметров через OpenWeatherMap API.

Для запуска установите зависимости:
```python 
pip install opencv-python numpy matplotlib requests
```
Откройте файл скрипта и замените ```YOUR_API_KEY``` на ваш действительный API ключ.
Запустите скрипт:
```bash
python3 cyclone_detector.py
```
Если изображение не найдено локально, скрипт автоматически скачает тестовый снимок с сервера NOAA.

Результат (изображение с выделенными кругами) будет сохранён как cyclone_detection.jpg и показан с помощью matplotlib.
